# Chapter 4: 关键词研究

## Core Idea
关键词研究是 SEO 的第一步：找到有搜索量、竞争度适中、与业务相关的搜索词。选对关键词比努力优化错误的关键词更重要。

## Frameworks Introduced
- **四步研究流程**：① 确定种子关键词（列出产品/服务、思考用户搜索词、看竞对）；② 用工具扩展列表（Google 搜索建议、Keyword Planner、Ahrefs 等）；③ 分析指标（搜索量、竞争度、CPC、关键词难度）；④ 筛选（有量 + 竞争适中 + 相关 + 有商业价值）。
- **KGR 公式（Keyword Golden Ratio）**：`KGR = allintitle 结果数 / 月搜索量`。<0.25 容易排名，0.25-1 中等，>1 竞争激烈。用法：Google 搜 `allintitle:关键词` 数结果。特别适合量化新词——工具对新词给不出 KD，但 KGR 只需要搜索结果数。
- **Google Trends 基准换算法**：Trends 只给相对热度。选一个已知搜索量的基准词与目标词同时对比，按倍数推算绝对搜索量，已用 Google Ads 数据验证过。
- **"什么时候不做站"决策法**：① 查 KD 所需外链数；② 查前 3 名实际流量天花板；③ 问天花板是否值得投入；④ 对比机会成本。
- **四类搜索意图**：信息型（了解）、导航型（找特定站）、商业型（比较）、交易型（购买）——内容类型必须匹配意图。

## Key Concepts
- **种子关键词**：与业务相关的基础词，是扩展的起点。
- **短尾关键词**：1-2 个词，量大、竞争激烈、转化低。
- **长尾关键词**：3 个以上词，量小、竞争低、转化高——新站应先做长尾积累权重。
- **关键词难度（KD）**：工具给出的 SEO 排名难度评分，常折算为进前 10 所需外链数。
- **新词优势**：出现 6 个月的新词（KD 50）比存在 1 年的老词（KD 30）更容易排名——新词 SERP 未被充分优化，先发优势巨大。
- **CPC**：每次点击成本，可判断关键词的商业价值。
- **关键词密度**：正文自然出现，约 1-2%，避免堆砌。
- **关键词布局分层**：首页放核心词、分类页放中等竞争词、内容页放长尾词。

## Mental Models
- 用"新词 > 低 KD"看机会：关键词的"年龄"和难度评分一样重要，先发是最大的 SEO 杠杆。
- 把竞争重新定义为"前 10-20 个真正在做 SEO 的结果"：你不是在和 200 万页面竞争。
- 用"投入产出比"过滤大词：KD 高 + 前三名流量天花板低 = 不做。

## Anti-patterns
- **只看搜索量选词**：量大不等于适合你，忽略竞争度和相关性必然失败。
- **忽视搜索意图**：内容不匹配用户意图，排名再高也不转化。
- **关键词堆砌**：密度失控会被 Google 惩罚。
- **不做长尾词**：新站直接打短尾是用卵击石。
- **选词一劳永逸**：搜索趋势会变，策略需要定期更新。

## Code Examples
```
KGR = allintitle 结果数 / 月搜索量
"ai image editor": 1790 / 200000 = 0.009  → 竞争极低
```
- **What it demonstrates**: KGR 计算实例——0.009 远低于 0.25，新站实际验证后数周内排进前 10。

## Reference Tables

## Worked Example
uuid generator 案例：Ahrefs 显示 KD 对应需要 71 条外链才能进前 10，但排名第一的站月访问量只有 430K、第二名仅 30K——高投入、低天花板，投入产出比极差，放弃。反例是 "ai image editor"：KGR 仅 0.009，新站几周内进前 10。对照结论：选词要同时看"难度"和"赢了能得到什么"。

## Key Takeaways
1. 选对关键词比努力优化错误关键词更重要。
2. 新站优先做长尾词，积累权重后再攻短尾。
3. KGR < 0.25 是低竞争信号，且是唯一能量化新词竞争度的免费方法。
4. 新词的先发优势巨大：新词可以在一周排名、两周上首页。
5. Google Trends 用基准词换算可以估算绝对搜索量。
6. 排名数据要现实：5.7% 的页面一年内上首页，高搜索量词仅 0.3%——除非是新词。
7. 布局分层：首页核心词、分类页中等词、内容页长尾词。
