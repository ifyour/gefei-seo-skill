# Chapter 3: Google 排名因素

## Core Idea
Google 排名是多个因素加权的结果：内容质量是最大权重因素，TDH 关键词决定你能否进入候选池，外链帮你进前 10，用户体验决定最终名次。

## Frameworks Introduced
- **排名三句话模型**：① Title 和 H1 关键词让页面进入候选池；② 外链帮你进入前 10 位；③ 网站体验（停留时间、跳出率、页面访问数）决定最终排名位置。三阶段缺一不可——很多站长只做了第一步就期望排名上升。
- **TDH 替代 TDK**：Keywords meta 标签已死十余年，Google 完全忽略它。现在关注 T（Title）、D（Description）、H（Headings）——H 标签是 Google 理解页面结构和关键词的重要信号，远超废弃的 Keywords。
- **权重表跟踪法**：用 FirstPageSage 的年度权重数据校准投入方向，关注趋势（外链↓、内容↑、新因素出现）而非绝对数字。

## Key Concepts
- **Title 标签**：权重约 15%，告诉搜索引擎页面主题的最重要元素；50-60 字符，关键词前置。
- **持续发布优质内容**：2025 年权重 23%，最大排名因素，且权重在上升。
- **用户参与度**：停留时间、跳出率等行为信号，2025 年权重 12%，正在反弹上升。
- **新鲜度（Freshness）**：2024 年新增因素，每年至少更新一次的页面平均提升 4.6 个 SERP 位置。
- **链接多样性**：2025 年新增因素（源自 2024 年 5 月 Google API 文档泄露），指不同类型网站的链接以及指向深层内页（而非全指向首页）的链接。
- **可信度（Trustworthiness）**：2024 年进入算法（5%），引用权威外链反而提升自己的信任分。
- **Dofollow / Nofollow**：Dofollow 传递权重；Nofollow 因"自然链接通常是 nofollow"的现实，现在也传递一定权重——"有就要，别嫌弃"。
- **移动优先索引**：Google 用移动版内容索引排名，移动端体验是硬指标。

## Mental Models
- 用"三级火箭"看排名：关键词点火 → 外链推进 → 体验巡航，缺一级都上不了轨道。
- 把"引用权威外链"当作信任背书而非权重泄漏：2024 年后这是加分项。
- 外链权重连年下降（2023 年 28% → 2025 年 13%）但仍不可省：新站没有外链进不了前 10。

## Anti-patterns
- **关键词堆砌**：密度失控会被惩罚，自然使用即可。
- **购买外链 / 链接农场 / 门页（Doorway Pages）/ 隐藏文本**：全部违反指南，惩罚风险高。
- **内容抄袭**：零原创价值，无法获得排名。
- **只优化标题不建外链**：第一级火箭点了火，没有推进力，永远进不了前 10。

## Code Examples
```html
<title>关键词 - 页面描述 | 品牌名</title>
```
- **What it demonstrates**: Title 最佳结构——关键词前置、描述居中、品牌收尾。

## Worked Example
两个页面同样优化了 Title 和 H1。A 站从 2023 年到 2025 年跟随权重表调整策略：持续更新内容（吃到内容↑和新鲜度红利）、外链来源多样化并指向内页（吃到链接多样性新因素）、引用权威来源（可信度加分），排名持续上升。B 站只做标题优化、外链全指向首页且锚文本单一，卡在第 15-20 位——正对应"三句话模型"中第二、三级火箭缺失。

## Key Takeaways
1. 内容质量是第一权重因素且还在加重，外链权重持续下降但仍是入场券。
2. TDH 取代 TDK：Keywords meta 已死，Headings 是活信号。
3. 排名三阶段：关键词进候选池 → 外链进前 10 → 体验定名次。
4. 新鲜度是实打实的因素：每年至少更新一次，平均提升 4.6 个位置。
5. 引用权威外链是信任加分，不是权重泄漏。
6. Nofollow 链接也有价值，全 dofollow 的外链组合反而可疑。
