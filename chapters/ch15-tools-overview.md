# Chapter 15: SEO 工具概览

## Core Idea
没有最好的工具，只有最适合的工具——免费工具（GSC、GA、Keyword Planner、Trends、PageSpeed Insights）已能满足大部分需求，付费工具按预算和需求选一个，重点是学会用而不是拥有多少。

## Frameworks Introduced
- **工具分层选型法**: 按 4 档用户选工具——①初学者（全免费组合，$0）：GSC + GA + Keyword Planner + Ubersuggest 免费版；②进阶（$100-200/月）：免费工具 + Ahrefs 或 SEMrush 二选一 + Screaming Frog；③专业（$300-500/月）：Ahrefs + SEMrush + Screaming Frog 付费版 + 专用工具；④企业（$1000+/月）：全专业工具 + 企业级方案。何时用：预算规划时。
- **必备/推荐/可选三级清单**: 必备（5 个免费 Google 工具）→ 推荐（Ahrefs 或 SEMrush 一个 + Screaming Frog）→ 可选（专用关键词/内容优化/外链分析/排名监控工具按需加）。
- **工具五大类目**: 免费工具、付费工具、专用工具（关键词/技术/内容/外链/排名监控）、浏览器插件（MozBar、SEOquake、Keywords Everywhere、Check My Links、Redirect Path）、选型建议。

## Key Concepts
- **Google Search Console**: 监控网站在 Google 搜索中的表现、索引状态、抓取错误、核心网页指标的免费官方工具，所有网站必须使用。
- **Google Analytics**: 跟踪流量、分析用户行为、监控转化的免费分析工具。
- **Ahrefs**: $99-$999/月，数据最全面、外链数据库最大，缺点是价格高、学习曲线陡。
- **SEMrush**: $119-$449/月，功能全面覆盖关键词/排名/内容营销/广告/社媒分析。
- **Moz**: $99-$599/月，界面友好、学习资源丰富，但数据量相对较小。
- **Screaming Frog**: 网站爬取和技术审计工具，免费版可爬 500 URL。

## Mental Models
- 把工具采购当"梯度升级"：先用免费工具摸清基本功能，需求增长后再补付费工具，不要一上来买全家桶。
- 用"二选一"控制预算：Ahrefs 和 SEMrush 高度重叠，选一个即可，除非预算到专业档。
- 把浏览器插件当作"随身仪表盘"：SEOquake、Keywords Everywhere 让你浏览任何页面/SERP 时都能看到指标。

## Anti-patterns
- **购买所有工具**: 按需求和预算选即可，免费工具已能满足大部分需求。
- **只囤工具不学用法**: 最重要的是学会使用工具，而不是拥有多少工具。
- **忽视工具更新**: SEO 算法和工具功能都在变化，需定期更新使用习惯和数据准确性认知。

## Worked Example
一个预算 $0 的新站起步：装 GSC + GA 验证监控、用 Keyword Planner 和 Google Trends 做关键词与趋势研究、PageSpeed Insights 查速度、Screaming Frog 免费版爬 500 个 URL 做技术体检、再装 SEOquake 和 Keywords Everywhere 插件日常看数据。这套组合覆盖了关键词→技术→监控全流程，等单月流量稳定后，再从 $100-200/月档补一个 Ahrefs。

## Key Takeaways
1. 五个免费 Google 工具是所有网站的必备底座。
2. Ahrefs 和 SEMrush 二选一即可，不必全买。
3. Screaming Frog 免费版 500 URL 对小站够用。
4. 选工具考虑四因素：预算、需求、学习曲线、数据准确性。
5. 官方文档是学习工具的最好资源。
6. 学会用工具 > 拥有工具。
