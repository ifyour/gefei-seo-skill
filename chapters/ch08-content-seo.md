# Chapter 8: 内容 SEO

## Core Idea
内容是 SEO 的核心：高质量、聚焦主题、满足搜索意图的内容是排名的基础，而首页的主题聚焦度在 2025 年仍然生死攸关。

## Frameworks Introduced
- **内容创作五要素**：标题（含关键词 + 吸引点击，50-60 字符，可用"数字+形容词+关键词+承诺"公式）、结构（H1→H2→H3 清晰层级）、长度（教程 1500-2000 字、深度指南 3000-5000 字、研究 5000+ 字，不注水）、关键词自然分布（标题/首段/小标题/正文/结尾）、多媒体（图片/视频/表格提升停留时间）。
- **内容生命周期管理**：优化现有内容（分析表现→更新→重新发布）→ 内容合并（多页相似时选最佳页合并 + 301 + 更新内链）→ 定期更新（核心内容每 3-6 个月，一般内容每年）。
- **长页面策略（Kayak 模式）**：一个 URL 覆盖一个关键词的全部用户意图，用模块化组合（表单、对比、FAQ、评价、教程），不要为每个子意图开单独页面。
- **工具站内容策略**：Google 不会运行你的工具，只能靠文字理解用途——工具页加说明文字、建教程页、写用例和 FAQ。
- **内容再利用**：文章 → 视频/信息图/播客/社媒帖子，一份内容多渠道分发。

## Key Concepts
- **内容为王**：满足用户需求、帮搜索引擎理解主题、自然吸引外链、延长停留时间。
- **搜索意图匹配**：内容类型必须匹配关键词背后的意图（学/买/比/找）。
- **首页关键词密度**：首页是全站权重最高的页面，其主题聚焦度决定 Google 对整站的理解——ChatGPT4o.ai 首页从 400 字被意外撑到 2000-3000 字，"GPT 4o"密度崩溃，流量骤降。
- **免费试用 = SEO 杠杆**：免登录即用的工具直接影响停留时间信号：满意关闭 = 正信号，回搜索页点别家 = 负信号。
- **CSS 伪元素隐藏重复文字**：40 个相同 "Play" 按钮干扰密度时，用 `.btn-play::after { content: "Play" }` 渲染按钮文字，HTML body 不含重复词，多语言只需换 CSS 文件。
- **内容合并**：相似薄内容 301 到最佳页面，集中权重。
- **新鲜度维护**：定期更新是排名因素（呼应 Ch 3 权重表）。

## Mental Models
- 把首页当"全站的自我介绍"：它的密度和主题决定 Google 怎么理解你的整站。
- 把长页面当"意图收容器"：一个关键词的所有子意图装进一个 URL，权重集中不分散。
- 把用户行为当"隐性评分"：Google 收集停留/返回搜索的数据，体验差 = 投票反对自己。

## Anti-patterns
- **内容过薄**：无法覆盖主题，无法排名。
- **首页内容失控**：任何把首页文本膨胀、稀释核心关键词密度的改动都是事故。
- **关键词堆砌**：密度失控、体验差、可能被惩罚。
- **内容过时**：信息陈旧导致排名下降，核心内容至少每 3-6 个月更新。
- **忽视用户意图**：内容与需求错位，排名再高也不转化。

## Code Examples
```css
/* 用 ::after 伪元素显示按钮文字，避免 HTML 中 40 个重复 "Play" */
.btn-play::after {
  content: "Play";
}
```
- **What it demonstrates**: CSS 伪元素方案——用户可见、爬虫的 body 解析中不出现重复文字；多语言切换只需替换 CSS 文件。

## Worked Example
Pixverse.ai 诊断：年访问量 6236 万、DR 61、2500+ 引用域名，但 38.6% 自然流量几乎全是品牌词，非品牌词零排名。根因三连：纯客户端渲染 → Googlebot 看到空 body，仅 208 页被索引；多语言用 JS 切换无 URL 区分；标题只有 "Home | Pixverse"。最小修复方案：React root 下加服务端渲染的 1200 字介绍区、标题改含 "AI Video Generator" 等业务词——权重足够，只差让 Google 看见内容。

## Key Takeaways
1. 为用户写作，为搜索引擎组织结构。
2. 首页的关键词密度和主题聚焦在 2025 年仍是生死线。
3. 一个长页面可以吃下一个关键词的全部意图（Kayak：一个 URL 年 62 万次点击）。
4. 工具站也必须做内容——Google 靠文字理解你的工具。
5. 免登录试用直接影响停留时间信号，是低成本的 SEO 杠杆。
6. 相似薄内容要合并 + 301，别让权重分散。
7. 核心内容每 3-6 个月更新，吃到新鲜度红利。
