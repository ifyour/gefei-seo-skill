# Chapter 1: 什么是 SEO

## Core Idea
SEO（搜索引擎优化）是通过让网站内容更好地匹配用户搜索需求，从 Google 等搜索引擎免费获得自然流量的系统工程。它不是作弊技巧，而是"被搜索到"的基础设施建设。

## Frameworks Introduced
- **SEO 三大支柱**：内容（关键词研究、页面优化）、技术（抓取、索引、速度）、权威（外链建设）。用这个框架诊断任何网站：先问能不能被爬到，再问内容是否匹配需求，最后问权威性够不够。

## Key Concepts
- **SEO（Search Engine Optimization）**：优化网站使其在搜索引擎自然结果中获得更高排名的实践。
- **自然流量（Organic Traffic）**：用户通过搜索引擎非广告结果进入网站的流量，不按点击付费。
- **SERP（Search Engine Results Page）**：搜索引擎结果页面，SEO 的最终战场。
- **关键词（Keyword）**：用户在搜索引擎中输入的词，是连接用户需求与网站内容的桥梁。
- **搜索意图（Search Intent）**：用户搜索背后的真实目的（了解/购买/比较/导航）。
- **白帽 SEO**：遵守搜索引擎指南、以用户价值为核心的优化方式，可持续。
- **黑帽 SEO**：试图操纵排名的作弊手段（隐藏文字、买链接），短期有效但终被惩罚。
- **排名（Ranking）**：页面在搜索结果中的位置，决定流量的大头。

## Mental Models
- 把 SEO 当作"投资"而非"投放"：内容、外链、技术改造都是一次性投入、长期回报的资产，与广告的"停投即停"截然不同。
- 把搜索引擎当作"最挑剔的用户"：凡是让真实用户困惑的东西，搜索引擎也看不懂。
- 用"漏斗"理解 SEO 工作：先被爬取，才能被索引；先被索引，才能排名——每层都是过滤漏斗。

## Anti-patterns
- **把 SEO 当作一次性任务**：排名是动态竞争的结果，停止优化就会被超越。
- **追求黑帽技巧**：买链接、隐藏文本等手段，短期收益换来长期惩罚甚至去索引。
- **只盯着排名不看流量质量**：排名高的词如果不匹配业务，带来的流量不会转化。

## Reference Tables
| 对比维度 | SEO | 付费广告（SEM） |
|---|---|---|
| 成本模式 | 投入时间/内容，点击免费 | 按点击付费 |
| 见效速度 | 3-6 个月起 | 立即 |
| 停止投入后 | 效果持续衰减但仍在 | 立即消失 |
| 可持续性 | 长期资产 | 纯支出 |

## Worked Example
一个刚上线的工具站没有排名。用三支柱框架诊断：技术上是前端渲染导致 Googlebot 看到空页面（技术问题，先修）；内容上没有针对任何关键词的页面（内容问题，做关键词研究）；外链为零（权威问题，从社区分享起步）。按"技术 → 内容 → 权威"顺序解决，这是任何新站的正确起点。

## Key Takeaways
1. SEO 的目标是获取免费的、可持续的自然搜索流量。
2. SEO = 内容 + 技术 + 权威，三者缺一不可。
3. SEO 是长期投资，见效通常需要 3-6 个月。
4. 白帽路线才是可持续路线，作弊手段的惩罚成本远高于收益。
5. 一切 SEO 决策的出发点是匹配用户搜索需求，而不是讨好算法。
