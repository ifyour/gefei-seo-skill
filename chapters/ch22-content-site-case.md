# Chapter 22: 内容网站 SEO 案例

## Core Idea
内容站的 SEO 核心是"内容为王 + 新鲜度信号"——CNN 用每天新 URL、日期化链接、LiveBlogPosting 结构化数据霸占选举报道排名；教程/资讯站靠内容深度和更新频率换取稳定排名。

## Frameworks Introduced
- **CNN 选举报道六件套**: ①每天发布新 URL（Google 热门故事只显示过去 24 小时内发布的页面，保持持续可见性）；②URL 含日期（如 /politics/live-news/trump-harris-election-10-15-24/）发送新鲜度信号；③LiveBlogPosting 结构化数据（告诉搜索引擎内容实时更新，获取热门故事红色"直播"徽章）；④每天 40-50 次更新刷新时间戳；⑤高质量相关图片（清晰候选人头像提升 CTR）；⑥首页链接重要内容（最强大页面引流，确保快速爬取索引）。何时用：任何时效性内容战场。
- **内容站三成功要素**: 内容深度（详细全面、深入讲解、实用建议、含案例）、更新频率（发新 + 更新旧、覆盖更多关键词）、用户体验（界面简洁、导航清晰、易读、移动友好）。
- **时效性内容策略**: 及时发布行业资讯、跟踪热点、独家报道、保持新鲜——资讯站的立身之本。

## Key Concepts
- **新鲜度信号**: URL 日期、dateModified 更新、持续发布，向 Google 传递内容时效性。
- **热门故事（Top Stories）**: Google 新闻聚合位，只展示过去 24 小时内发布的页面。
- **LiveBlogPosting**: Schema.org 类型，声明实时更新内容，换取"直播"徽章和更高 CTR。
- **内容深度**: 用户信任度、停留时间、跳出率的根本来源，排名稳定的基础。
- **dateModified**: 内容最后修改时间戳，随每日更新刷新，是新鲜度的直接信号。

## Mental Models
- 把新闻 SEO 当"抢时效的游戏"：不是一次性排名，而是每天用新 URL 重新进场。
- 把结构化数据当"入场券"：LiveBlogPosting 让你有资格进热门故事并戴"直播"徽章。
- 把首页当"权重泵"：首页链向当天最重要的报道，加速爬取和索引。

## Code Examples
```json
{
  "@context": "https://schema.org",
  "@type": "LiveBlogPosting",
  "headline": "Election 2024 Live Updates",
  "datePublished": "2024-10-15T00:00:00Z",
  "dateModified": "2024-10-15T23:59:59Z"
}
```
- **What it demonstrates**: LiveBlogPosting 结构化数据的最小实现——声明类型、发布时间、最后修改时间，获取直播徽章资格。

## Anti-patterns
- **内容抄袭/过时/不相关**: 内容质量低是被惩罚和排名崩塌的直接原因。
- **更新频率低**: 内容过时 → 流量下降 → 排名下降 → 用户流失的连锁反应。
- **忽视技术优化**: 页面慢、移动端不友好、结构化数据缺失，深度内容也跑不起来。
- **只发不更**: 旧内容不更新，浪费已有排名资产。

## Reference Tables
三个案例打法对比：

| 案例 | 核心策略 | 关键特征 |
|------|---------|---------|
| CNN 选举报道 | 每日新 URL + 日期 URL + LiveBlogPosting + 日更 40-50 次 | 热门故事霸榜 + 直播徽章 |
| SEO 教程网站 | 内容深度 + 高更新频率 + 用户体验 | 用户粘性高、排名稳定 |
| 行业资讯网站 | 时效性内容 + 内容质量 + 结构化数据 | 品牌知名度高 |

## Worked Example
复刻 CNN 打法到一个直播事件：为事件建每天一个的 URL（含日期后缀），页面标记 LiveBlogPosting 并持续刷新 dateModified，编辑团队每天做 40-50 次小更新（每条更新刷新时间戳）；配清晰高质量的相关图片；把当日 URL 挂到首页重要位置加速爬取索引。结果：持续出现在 Google 热门故事、带红色"直播"徽章，CTR 和流量远超单篇静态报道。

## Key Takeaways
1. 热门故事只认 24 小时内的新页面——时效性战场必须每天发新 URL。
2. URL 含日期 + dateModified 刷新是两个低成本的新鲜度信号。
3. LiveBlogPosting 结构化数据 = 热门故事 + 直播徽章 + 更高 CTR。
4. 首页链接当日重要内容，加速爬取和权重传递。
5. 教程/资讯站的长期打法是深度内容 + 更新频率 + 体验三者叠加。
6. 内容站的四个常见死因：抄袭、过时、低更新频率、技术拖后腿。
