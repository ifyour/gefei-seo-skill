# Chapter 17: Google Analytics

## Core Idea
GA 补足 GSC 看不到的"到站之后"——流量来源、用户行为、转化路径，用 GA4 的事件驱动模型，数据驱动地优化着陆页和转化率。

## Frameworks Introduced
- **GA 核心报告地图**: ①实时报告（验证跟踪代码、监控活动）；②用户获取报告（流量来源分类分析）；③用户行为报告（所有页面/着陆页/行为流）；④转化报告（设置目标、跟踪转化路径）。何时用：装好代码后从这四块入手。
- **流量来源五分类**: 自然搜索（搜索引擎免费流量）、直接（输网址/书签）、引荐（其他网站链接）、社交（社媒）、付费搜索（广告）。何时用：在获取报告里找出高质量来源、优化营销策略。
- **转化目标四类型**: 目标网址、时长、页面/会话、事件。何时用：装完代码第一件事就是设转化目标，否则没有转化数据。
- **SEO 三用法**: 监控效果（自然流量趋势/热门词/着陆页表现/转化率）、发现机会（高流量低转化页面、高跳出率页面）、评估 ROI（ROI = (SEO 收入 − SEO 成本) / SEO 成本，需要自然流量、转化率、客单价、成本四个数据）。

## Key Concepts
- **用户（Users）**: 独立访问者，基于 Cookie 识别，分新用户和回访用户。
- **会话（Sessions）**: 一次访问，30 分钟不活动后结束，可含多个页面浏览。
- **跳出率**: 只浏览一个页面就离开的会话比例，越低越好。
- **着陆页报告**: 用户进入网站的入口页数据——会话数、新用户、跳出率、转化率。
- **事件跟踪**: 用户与网站的互动（按钮点击、下载、视频播放、表单提交），不涉及页面加载，可自定义。
- **细分**: 基于条件的用户子集（新/回访、移动/桌面、来源、地区），用于深入分析。
- **归因模型**: 分配转化功劳的方式——最终点击、首次点击、线性、时间衰减。

## Mental Models
- 把 GA 当"到站后的显微镜"：GSC 告诉你谁点了你，GA 告诉点进来的人做了什么。
- 用"行为流"找流失点：看到用户在哪一步离开，就优化那一步。
- 用"高流量低转化"清单驱动优化：流量大却不转化的页面是性价比最高的改进对象。

## Anti-patterns
- **只装代码不设目标**: 没有目标就没有转化数据，分析无从谈起。
- **不过滤内部流量**: 自己团队的访问污染数据。
- **用旧版 GA 的指标思维硬套 GA4**: GA4 是事件驱动模型、更注重隐私，建议直接用 GA4。
- **把 GA 数据延迟当故障**: 通常延迟 24-48 小时，实时报告看当前数据。

## Code Examples
```html
<!-- Google Analytics（GA4）跟踪代码 -->
<script async src="https://www.googletagmanager.com/gtag/js?id=GA_MEASUREMENT_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'GA_MEASUREMENT_ID');
</script>
```
```javascript
// 自定义事件跟踪
gtag('event', 'click', {
  'event_category': 'button',
  'event_label': 'signup',
  'value': 1
});
```
- **What it demonstrates**: 基础安装代码与自定义事件上报——事件驱动是 GA4 的核心模型。

## Worked Example
流量增长缓慢、转化率低的排查：①获取报告发现自然搜索占比低、部分词流量高但转化低、部分页面跳出率高；②行为报告发现停留短、浏览页数少、流失点多；③转化路径分析发现路径太长、某环节流失严重；④对策——调整关键词策略、优化页面内容、简化转化流程、提升体验；⑤实施后监控。结果：自然搜索流量增长 50%，转化率提升 30%。

## Key Takeaways
1. 装代码后第一件事：设转化目标 + 过滤内部流量。
2. 获取报告的五类流量来源是判断渠道质量的基础。
3. 着陆页报告抓"高跳出率页面"，逐个分析原因优化。
4. 行为流和漏斗帮你找到流失环节，只优化那一环。
5. GSC 统计搜索展示点击，GA 统计到站访问，两者互补。
6. SEO ROI 需要四个数据：自然流量、转化率、客单价、SEO 成本。
