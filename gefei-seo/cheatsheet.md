# Cheatsheet — Google SEO 实战教程（触境即决）

## 决策规则

| 情境 | 动作 | 原因 |
|---|---|---|
| 新词 KGR<0.25 | 立即做页面 | 竞争池空，先发优势 |
| 6 个月新词 vs 1 年老词（KD 更高） | 选新词 | SERP 未被优化 |
| 新站 <6–12 月 / 引用域<100 / DR<40 | 禁止程序化批量页 | 批量=必死 |
| 纯 CSR / SPA 裸奔 | 先上 SSR | Googlebot 不跑 JS |
| 页面 10 名开外 | 加外链 | Title/H1 已进候选池 |
| 前 10 内不动 | 优化体验信号 | 体验决定最终位次 |
| 内页想加外链 | 先走内链五步检查 | 外链 $200–400/条 |
| 排名突降 | 先查蜜月期结束 | 新站 1–3 月回落正常 |
| 多语言上线 | 子目录 + 独立 URL + hreflang | JS 切语言=白做 |
| 工具站没流量 | 补内容页 | Google 只看文字 |

## 硬数字

- **Title** 50–60 字符，唯一，关键词前置+品牌名；**Description** 150–160 字符
- **H1** 每页唯一含主词；关键词密度 1–2%
- **内链** 每页 3–5 个描述性锚文本；所有页面 **3 次点击内**可达
- **内容长度**：教程 1500–2000 / 深度指南 3000–5000 / 研究 5000+ 字
- **更新**：核心内容每 3–6 月；页面每年至少更新一次（+4.6 SERP 位）
- **外链成本**：Guest Post $200–400/条；DR90 一条 > DR30 一百条；见效 3–6 月
- **程序化节奏**：100 页进前 20 → 先发 10 个 → GSC 观察 → 20/50/100
- **恢复时间**：内容 1–3 月 / 外链 3–6 月 / 算法 3–12 月 / 手动复审 2–4 周
- **2025 权重**：内容 23%｜TDH 14%｜外链 13%｜专业度 13%｜体验 12%
- **GSC 节奏**：每周搜索报告 / 每月索引+链接 / 每季度全面
- **移动端**：按钮 ≥44×44px；HTTPS 必备（Let's Encrypt 免费）

## 决策树：排名不上去

```
页面没被索引？→ GSC URL 检查 → robots/noindex/CSR 渲染问题
└─ 已索引
   ├─ 50 名开外 → Title/H1 关键词、On-Page 检查
   ├─ 11–50 → 外链不足 → 内链提权 → 外链
   └─ 前 10 不动 → 停留时间↑ 跳出率↓ 页访问↑（免费试用/内容模块）
```

## Tells & Smells

- 全站 dofollow 外链 → 可疑组合，Google 会盯
- 单一锚文本 → 展示量崩塌先兆
- 首页字数突然变化 → 检查核心词密度（ChatGPT4o.ai 惨案）
- 薄内容 + 过期域名 + 爆炸增长 → 被 K 三件套
- Ads 搜索量突跳但 Trends 平稳 → 数据合并异常，可能是隐藏机会
- 评论区一片和谐 → 快过气了（内容运营同理）

## AI SEO 速查

- 品牌名布局 ≥3 个高权重平台：Reddit/Quora/YouTube/行业媒体
- 纯文本 URL（非超链接）也能被 AI 引用
- 可引用内容：结构化、有数据来源、具体数字、原创观点
- 验证：定期在 ChatGPT/Perplexity 搜自己品牌名
