# Chapter 5: 页面 SEO（On-Page SEO）

## Core Idea
页面 SEO 是优化网页内部元素（TDH、内容、图片、内链、URL），让搜索引擎准确理解页面主题。它是排名的地基，但不是全部。

## Frameworks Introduced
- **TDH 三要素**：T（Title，权重约 15%，50-60 字符、关键词前置、结尾加品牌名）；D（Description，不是排名因素但影响点击率，150-160 字符、含 CTA）；H（Headings，H1 唯一且含主关键词，H2 主章节、H3 子章节）。Title 和 H1 可以相同。
- **On-Page 检查清单法**：发布前按 Title / Description / Headings / 内容 / 图片 / 链接六组清单逐项检查，把优化变成可重复流程。
- **内链四原则**：描述性锚文本、链接到相关页面、每页 3-5 个内链、重要页面获得更多内链。

## Key Concepts
- **Title 标签**：告诉搜索引擎页面主题的最重要元素，每个页面必须唯一。
- **Meta Description**：不直接影响排名，但决定搜索结果中的展示文案和 CTR。
- **H1 标签**：每页有且只有一个，包含主要关键词。
- **Headings 层级**：H1→H6 表达内容骨架，层级清晰帮助搜索引擎理解结构。
- **Alt 属性**：图片的文字描述，兼顾可访问性和图片搜索流量。
- **锚文本**：链接的文字部分，应描述目标页内容而非"点击这里"。
- **URL 结构**：小写字母、连字符分隔、简短、含关键词、无特殊字符。
- **关键词密度**：保持 1-2%，用语义相关词替代重复堆砌。

## Mental Models
- 把 Description 当"免费广告文案"：不加分排名，但直接决定用户是否点你。
- 把 Headings 当"目录"：既是用户的浏览地图，也是 Google 的结构理解输入。
- 用"为用户写"一票否决所有纠结：任何为搜索引擎而非用户的写法，长期都是减分。

## Anti-patterns
- **关键词堆砌式 Title**（如"SEO, SEO教程, SEO优化, SEO入门"）：既不自然又容易被判定操纵。
- **"点击这里"式锚文本**：浪费了告诉 Google 目标页主题的机会。
- **图片用 IMG_1234.jpg 命名、无 Alt**：丢掉图片搜索流量和语义信号。
- **带参数的动态 URL**（index.php?id=123&cat=456）：可读性差且易产生重复内容。
- **为了长度注水**：长内容排名好，但注水会被用户行为信号反噬。

## Code Examples
```html
<!-- 好的 Title -->
<title>Google SEO 入门教程 - 从零开始学习搜索引擎优化 | SEO Book</title>
<!-- 好的锚文本 -->
<a href="/guide/keyword-research">学习关键词研究方法</a>
<!-- 图片优化 -->
<img src="seo-workflow.webp" alt="SEO 优化工作流程图">
```
- **What it demonstrates**: Title 结构、描述性锚文本、图片三件套（描述性文件名 + WebP + Alt）的正确写法。

## Reference Tables
| 元素 | 长度建议 | 是否排名因素 | 关键要点 |
|---|---|---|---|
| Title | 50-60 字符 | 是（~15%） | 唯一、关键词前置、品牌收尾 |
| Description | 150-160 字符 | 否（影响 CTR） | 唯一、含 CTA |
| H1 | 一句短语 | 是（Headings） | 每页一个、含主关键词 |
| 关键词密度 | 1-2% | 间接 | 自然使用、用语义词 |

## Worked Example
一个教程页面发布前过检查清单：Title "关键词 - 页面描述 | 品牌名"，56 字符 ✓；Description 含关键词和 CTA，155 字符 ✓；H1 唯一含主词，H2/H3 层级清晰 ✓；正文首段出现关键词、密度 1.5%、配 WebP 图带 Alt ✓；3 个描述性内链到相关教程 ✓；URL 为 /guide/keyword-research ✓。全部通过才发布——把"优化"变成不遗漏的流程，而不是凭感觉。

## Key Takeaways
1. TDH 是页面 SEO 的三大核心，Keywords meta 已无意义。
2. Description 不影响排名但影响点击率，值得认真写。
3. 每页 3-5 个描述性内链，重要页面要多被链接。
4. URL 小写 + 连字符 + 简短 + 含关键词。
5. 图片三件事：描述性文件名、Alt、压缩（WebP 优先 + 懒加载）。
6. On-Page 是基础而非全部，需结合技术 SEO 和外链才有排名。
