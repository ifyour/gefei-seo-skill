# Chapter 9: 程序化 SEO

## Core Idea
程序化 SEO 用模板 + 数据批量生成页面覆盖长尾关键词，但新站批量上页面等于自杀——正确的姿势是"先手工验证，再小批量试水，再规模化"。

## Frameworks Introduced
- **关键词矩阵法**：`核心词 + 修饰词`（城市+服务、产品+特性、品牌+对比）批量生成页面主题。先生成矩阵，再评估每个组合是否值得一个页面。
- **模板五件套**：Title 模板（`{关键词} - {修饰词} | {品牌名}`）、Description 模板、H1 模板、内容模板（定义→详情→总结 CTA）、内链模板。模板必须让每个页面有独特数据填充。
- **新站发布协议（本书最关键的方法论）**：新站判定（域名 <6-12 个月 / 引用域名 <100 / DR <40 / 进前 20 的页面 <100，任一满足）→ 绝对不能批量上页面。正确节奏：① 前 3-6 个月逐个手工做页；② 约 100 个页面进前 20 后，小批量发 10 个程序化页；③ 在 GSC 观察收录排名；④ 表现好再扩到 20、50、100。
- **首页新鲜度加速**：首页展示最新 N 个内页链接——Googlebot 最频繁爬首页，此法有人一个月收录 10 万+ 页（甚至没 sitemap）。
- **CDSD 理论（共识驱动搜索需求）**：搜索量来自"多人独立用相同词语表达相同需求"。新需求出现 + 先发落地页 = 以最小竞争获取巨大流量。
- **"一词一页"原则**：每个页面针对一个关键词，不为数量牺牲质量。

## Key Concepts
- **程序化 SEO**：模板 + 数据自动生成大量针对特定关键词的页面。
- **典型页面类型**：城市+服务、产品对比（A vs B）、工具结果页、目录页。
- **数据要求**：准确、完整、时效、唯一——数据质量决定页面质量上限。
- **新站观察期**：Google 对新站的质量审视阶段，批量页面会触发警报。
- **低质量信号**：内容重复/相似、过薄、堆砌、无独特价值——算法或人工惩罚（降权、去索引）。
- ** canonical/noindex 控制**：对低价值程序化页收权的技术手段。
- **质量检查工具**：Screaming Frog、Sitebulb、GSC。

## Mental Models
- 把程序化页面当"工厂产品"：模板是生产线，数据是原材料——原材料差，量产的只是垃圾。
- 把新站当"试用期员工"：先一件件把事做漂亮（手工页），建立信用后才允许上自动化流程。
- 把首页当"新页面的公告栏"：每个新页面都在首页亮相，就是最快的收录通道。

## Anti-patterns
- **新站批量上页面**：触发质量警报，"新站批量上页面 = 必死"。
- **模板内容空心化**：只有模板框架没有独特数据，等同重复内容。
- **为数量牺牲质量**：页面上万但大量不收录，反伤整站信任。
- **不做质量抽检**：程序化更需要定期用 Screaming Frog/GSC 巡检。

## Code Examples
```
Title: {城市} SEO 服务 - {服务类型} | {品牌名}
H1:    {城市} 专业的 {服务类型} 服务
内容:  我们为 {城市} 地区的企业提供 {服务类型} 服务...
```
- **What it demonstrates**: 模板变量结构——每个槽位必须由真实、独特的数据填充，而非通用套话。

## Reference Tables
| 阶段 | 动作 | 门槛 |
|---|---|---|
| 0-6 个月 | 手工逐页做，一词一页 | 无 |
| ~100 页进前 20 | 小批量程序化 | 先发 10 页 |
| GSC 观察 | 看收录与排名 | 确认信号 |
| 扩量 | 10 → 20 → 50 → 100 | 每批表现良好 |

## Worked Example
getimg.ai 实战："Ghibli AI" 在社交媒体形成新需求（CDSD 信号），该站快速发布对应落地页。结果：一个月内月访问量从 160 万涨到 1240 万（+1080 万）。逻辑链：新词 KGR 极低（Ch 4）→ 先发落地页 → 几乎无竞争拿下排名。配合首页新鲜度技巧，新页面收录极快。

## Key Takeaways
1. 程序化 SEO 有效，但 Google 能识别低质量批量页面。
2. 新站绝对不能批量上页面——先手工积累，100 页进前 20 是解锁条件。
3. "一词一页"，每个页面必须有独特数据支撑的价值。
4. 首页展示最新内页链接是免费的收录加速器。
5. 搜索量来自共识：盯 Google Trends，新需求出现就先发落地页。
6. 用 canonical / noindex 收权低价值页面，控制索引质量。
