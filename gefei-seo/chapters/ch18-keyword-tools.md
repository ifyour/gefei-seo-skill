# Chapter 18: 关键词研究工具

## Core Idea
关键词研究是 SEO 的基础——用种子词扩展出长列表，按搜索量、竞争度、搜索意图、商业价值四维筛选，选对词事半功倍。

## Frameworks Introduced
- **五步关键词研究流程**: ①确定种子关键词（核心业务词、竞对分析、用户需求、头脑风暴）→ ②扩展关键词列表（工具、搜索建议、相关搜索、竞对）→ ③分析指标（搜索量/竞争度/难度/意图）→ ④筛选（月搜索量 > 100、竞争度适中、与业务相关、有商业价值）→ ⑤分组规划（按主题和意图分组、排优先级）。何时用：任何新站或新内容线启动时。
- **KGR 公式**: KGR = allintitle 结果数 / 月搜索量。KGR < 0.25 容易排名，0.25-1 中等，> 1 竞争激烈。怎么用：Google 搜 `allintitle:关键词` 记录结果数，除以月搜索量。
- **搜索意图四类型**: 信息型（想了解）、导航型（找特定网站）、商业型（比较产品）、交易型（想购买）。分析方法：看搜索结果页面判断 Google 认定的意图，创建匹配的内容类型。
- **竞对关键词法**: 用工具查竞对的关键词，找出"他们排名好但竞争度低"的词，做比他们更好的内容。

## Key Concepts
- **种子关键词**: 研究起点——核心业务词，围绕它用工具扩展。
- **KD（关键词难度）**: 排名难度评分 0-100（Ahrefs/SEMrush/Moz 均有类似指标）。
- **长尾关键词**: 搜索量小、竞争低、转化率高、更具体的词。
- **allintitle**: Google 搜索运算符，返回标题包含该关键词的页面数量，KGR 公式的分子。
- **Google 搜索建议/相关搜索**: 免费实时的需求来源——下拉建议反映真实搜索，页面底部"相关搜索"扩展同族词。

## Mental Models
- 把关键词当"投资标的"：搜索量是回报，KD 是风险，意图匹配是流动性——三个都要看。
- 用"问题型关键词"喂内容创意：Answer The Public 的问题/介词/比较型关键词直接映射成 FAQ 和文章选题。
- 把竞对当免费的关键词数据库：他们验证过的词，你直接复用并做得更好。

## Anti-patterns
- **只看搜索量选词**: 高搜索量常伴随高竞争和模糊意图，必须结合 KD、KGR 和商业价值。
- **忽视搜索意图硬做内容**: 信息型词上放销售页，怎么优化也排不上去。
- **只用一个种子词研究**: 多个种子词交叉扩展才能覆盖足够的长尾。
- **不导出不沉淀**: 关键词要导出分组、排优先级，形成内容规划。

## Worked Example
围绕 "file type checker" 做一轮研究：种子词 = file type checker / identify file type / what type of file is this。用搜索建议和相关搜索扩展出长尾 "how to check file type on windows"、"how to identify unknown file type"。逐词算 KGR：某词 allintitle 结果 400、月搜索量 2000，KGR = 0.2 < 0.25，标记为优先做；另一个词 allintitle 8000 / 搜索量 3000 = 2.7 > 1，先放弃。最终按信息型/交易型意图分组，长尾意图词优先上内容。

## Key Takeaways
1. 研究流程五步：种子→扩展→分析→筛选→分组规划。
2. KGR < 0.25 是新站找低竞争词的快速过滤器。
3. Keyword Planner 数据最准（范围值），付费工具胜在 KD 与竞对数据。
4. 搜索意图必须匹配内容类型，看 SERP 判断 Google 的认定。
5. 长尾词是中小站的立足点：量小、竞争低、转化高。
6. 筛选标准参考：月搜索量 > 100 + 竞争适中 + 业务相关 + 有商业价值。
