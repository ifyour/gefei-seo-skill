# Chapter 7: 外链建设

## Core Idea
外链是 Google 排名的重要推力——它帮你从"有排名资格"推进到"前 10 位"。质量远重于数量，可持续的外链来自真正有价值的产品和内容。

## Frameworks Introduced
- **外链质量五指标**：来源网站权重、来源内容相关性、锚文本含关键词、链接位置显眼、Dofollow。评估任何链接机会都用这五条打分。
- **八大建设方法**：内容营销（原创研究/工具/信息图）、客座文章、断链建设、资源页链接、竞对分析、社区参与、品牌提及转化、速度优势（抢先发布）。按资源禀赋选择组合。
- **新站三阶段外链节奏**：前 3 个月专注内容 + 基础外链（社媒/目录）；3-6 个月开始客座文章和竞对分析；6 个月后规模化（资源页、断链建设）。
- **内页外链五步检查法**：① On-Page 做好了吗？② 页面权重和内容深度够吗？③ 前 10 名对手实力如何？④ 先用内链提权，不够再加外链；⑤ 给够时间了吗（3-4 个月）？——四句话原则先行：先页面 SEO，先内链，先评估对手，先给时间。
- **锚文本多样化配比**：品牌词 + URL + 通用词 + 关键词混合，避免过度优化。

## Key Concepts
- **Dofollow / Nofollow**：Dofollow 传递权重；Nofollow 因自然链接多为 nofollow 的现实，现在也传递一定权重——"有就要，别嫌弃"。全 dofollow 组合反而可疑。
- **PBN（私有博客网络）**：一群受控站点互链操纵排名，Google 重点打击对象；避免被判定为 PBN：每站有独立价值、真实流量、不同模板、自己的品牌。
- **断链建设（Broken Link Building）**：找相关网站的失效链接，做出替代内容后联系站长替换。
- **外链真实成本**：Guest Post $200-400/条；一条 DR90 链接 > 100 条 DR30；见效周期 3-6 个月；是持续投入而非一次性。
- **外链速度控制**：增长要平稳自然，突增大量外链是危险信号。
- **品牌提及转化**：监控无链接的品牌提及，联系站长补上链接。

## Mental Models
- 把外链当"选票"：一张高权重相关选票 > 一百张垃圾选票。
- 把速度当外链策略：在内容稀缺时第一个上线有价值的东西，社区会自发给你外链。
- 用"投资组合"看锚文本：单一关键词锚文本 = 集中投资，一次算法调整就爆仓。

## Anti-patterns
- **购买外链 / 链接农场 / 自动化群发**：全部违反指南，短期收益换长期惩罚。
- **PBN**：破坏搜索生态，Google 重点识别和打击。
- **锚文本单一化**：真实案例——展示量从 770/天暴跌到 47/天，恢复方法是补多样化锚文本，2 个月回到 637/天。
- **只追求 Dofollow**：自然组合应含 nofollow；嫌 nofollow 是在丢弃最有价值的自然链接信号。
- **新站就大规模建外链**：没有内容基础，外链效果差且模式可疑。

## Code Examples
```html
<a href="https://example.com" rel="nofollow">链接</a>
```
- **What it demonstrates**: nofollow 标注方式——用户生成内容、付费链接场景应使用。

## Worked Example
GPTsHunter.com 在 OpenAI DevDay 后一天上线，单页静态站 + JSON 数据部署在 Cloudflare Pages，4 天获得 4,700 条外链、来自 33 个引用域名。做对三件事：速度（内容稀缺期第一个上线）、简单（单页静态）、真正解决用户痛点（社区自发传播）。教训：最好的外链策略是"做第一个有价值的产品"，而不是去"要"外链。

## Key Takeaways
1. 外链质量 >> 数量：一条 DR90 > 100 条 DR30。
2. Nofollow 也有价值，自然组合必须多样化。
3. 锚文本必须多样化，单一关键词锚文本会导致流量暴跌。
4. 外链是持续投入，停止建设排名会回落；见效周期 3-6 个月。
5. 内页加外链前先过五步检查：On-Page → 内链 → 对手实力 → 时间。
6. 避开 PBN、买链、群发——惩罚成本远高于收益。
7. 速度即外链：先发的有价值产品会赢得自发外链。
